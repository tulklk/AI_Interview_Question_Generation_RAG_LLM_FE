# QA Bug Summary Report: Bug thật của sản phẩm

**Phạm vi:** Các lỗi thật trong sản phẩm (dead button, race condition, dữ liệu giả mạo, thiếu xử lý lỗi...) được tự phát hiện và tự sửa trong suốt quá trình phát triển — qua kiểm thử thủ công, đối chiếu UI với dữ liệu thật, và đọc/đối chiếu file `tests/unit/*.test.ts(x)` khi viết tài liệu test case. Mỗi dòng đều gắn commit sửa thật (`git log`), không phải tình huống giả định. Không bao gồm sequence diagram, không bao gồm lỗi trong chính script/pipeline sinh tài liệu QA (đó là công cụ nội bộ, không phải bug sản phẩm).

**Phương pháp:** Đối chiếu UI với dữ liệu thật trong DB trong quá trình dùng thử sản phẩm; đối chiếu số liệu/nội dung tài liệu test case với trạng thái thật của test suite (`npx vitest list`); xác nhận từng bug qua đúng commit sửa (`git show <hash>`) và (khi có) chạy lại test hồi quy tương ứng.
